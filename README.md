Analicemos ¿Qué ocurre en cada caso presentado anteriormente con los operadores y porqué JS me permite esto?



R// En JavaScript los operadores son flexibles porque el lenguaje es débilmente tipado; el + puede sumar o concatenar, y gracias a la conversión implícita de tipos y la precedencia de operadores se permiten combinaciones que otros lenguajes no aceptarían.



Analicemos ¿El comportamiento de los flujos de control es similar a otros lenguajes y ambientes de desarrollo?



R// Sí, estructuras como if/else, switch o los bucles funcionan casi igual que en C, Java o Python; la diferencia es que en JS no se usan tipos estrictos, pero la lógica del control de flujo es la misma.
